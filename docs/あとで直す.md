## あとでよい（低）

**お金・営業日**
- 取り込みのない月（8月など）を開くと、売上0円・差し引き −店長報酬 と出る
- 分析の「傾向」が、ポイントを売上に含めない設定を無視する。時間帯の集計に12時の固定値が残る
- 設定の入力に範囲の確認がない（切り替え時刻に空欄や30を入れられる、運用開始日を空にすると試運転の除外が効かない）
- 固定費は、運用開始日より前の月は黙って集計から外れる。仕入れの科目は `calc.js` で固定（設定を変えても月次の内訳に効かない）
- 完全移行の日を10/20など途中に早めたとき、スプシの「10月」タブにアプリの数字は入らない（分析の月次には入る）

**同期・GAS**
- `appendLog_` が `changePin` の経路でロックの外にある（同時に追記すると行が重なるかも）
- `setup()` の書式設定が約160回の `setNumberFormat`。1年後は数分かかりうる（6分には収まる見込み）
- `ensureTriggers_` は関数名だけで判定する。許可が切れたトリガーは「設定済み」と出て直らない
- 毎月20日のトリガーは、ロック待ちの時間切れだと握りつぶされる（最初の閉店で月のタブはできるので、被害は小さい）
- `handleSheetEdit` が、シート名を見る前に設定を読む（実害は小さい）
- 失敗した操作が、失敗の一覧に入っても、画面には赤い表示だけで中身が分からない
- 閉店のあとに追加を足した（合計が増えた）組が、退店のまま「受け取りが足りない」状態になる（受け取りの足りない退店を知らせる表示がない）

**権限・秘密・端末**
- 暗証番号の総当たり：試行の数え方が、鍵なしの「読む→数える→書く」で、同時に送ると5回で止まらない。バイトが間違えると店長も10分入れない。（直し：`login_` を `withLock_` に入れ、失敗回数と解除時刻をスクリプトプロパティに置く。`changePin` で「0000」「1234」を断る）
- `changePin` のあとも、古い店長用トークンが2時間生きる
- 店長ロック直後の `logout` が、送信中の店長の記録より先に着くと、その記録は「送れなかった」に入る
- 古い版の画面：新しい `sw` が入っても、開きっぱなしのページは再読み込みされない（更新の通知がない）
- 店長モードで端末に入った勤怠・仕入れ・固定費・操作履歴・時給は、ロック後もIndexedDBに残る（画面では隠れる）
- 共有トークンを変えたあと、送信待ちが0件だと「送信済み」のままで気づけない（`pull` は失敗を握りつぶす）
- テーブル名に `constructor`・`__proto__` を送ると、バッチ全体が `server` エラー（`hasOwnProperty` で確かめる）
- `notify_` が、共有トークンと初期の暗証番号を、実行ログ（`console.log`）に残す
- 回収の禁止は type の完全一致（「回収 」のように空白が付くと新規行が通る。集計では回収にならず、影響は小さい）
- 古い端末の時計が進んでいると、店長の直しが黙って捨てられる（`bootstrap` の `serverTime` と比べて警告する案）
- 旧 `index.html` に、旧GASのURL（誰でも読み書きできる）が残っている。そのデプロイを、試運転の前にアーカイブする

**手順書・文書**
- `handover.md` が10/14のまま：トリガー（スプシの編集・毎月20日）、隠しタブ（月のひな形・シフト表のひな形・過去の日別・過去の月次）、スクリプトプロパティ（`LEGACY_URL`・`MONTH_TPL_HOW`・`PLANSNAP:` 〜）が抜けている。引き継ぎで新しい管理者が `setup` を実行すると、`getProjectTriggers` は実行した人の分だけなので、林さんのトリガーと二重になる
- `セットアップ手順.md`：タブ一覧に「レジの出し入れ」がない。トリガーの設定結果の説明がない。トークン作り直しの注意が「`rotateToken` をエディタで実行」のまま（メニューの確認付きの手順と食い違う）。保護は `setup` で付く表だけで、月のタブ・月次・突き合わせ・ひな形・過去の日別/月次は付け直さない
- `試運転の準備.md` の「困ったとき」に、暗証番号を5回間違えると10分入れない説明がない
- `取り込みの対応表.md`：「C〜F（列1〜列4）」は「列2〜列5」に。管理シートの名前が「（管理職員用）」と「（管理）」でそろっていない
- `CLAUDE.md`：「追加の金額は設定で変更可」とあるが、設定画面に編集欄がない（`quickAdds`・`cashInReasons`・`shiftColumnChoices`）。`openTime`・`closeTime` は使われていない。「1. 来客・会計」の節に、新しい決まりと矛盾する記述が残る（「0円は会計できない」と「0円で退店する」、区分と種類、「チェックで会計済みへ」）。「設定値はハードコードしない」とあるが、「加奈」が GAS（`appMonthDays_`）に、「岡本さん」が画面の文言にある。設定画面の名前（「会計を取り消す理由」）と GAS（「店内に戻す理由」）が食い違う
