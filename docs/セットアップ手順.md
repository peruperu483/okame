# 新しいスプシとGASのセットアップ手順

林さん向けの手順です。初めてでも迷わないように、押すボタンの名前まで書いています。
パソコンのChromeで作業してください（15〜20分ほど）。

> 画面の文言は、Googleの更新で少し変わることがあります。似た名前のボタンを選べば大丈夫です。

---

## 0. 用意するもの

- 林さんのGoogleアカウント（スプシ・GASの持ち主になり、ずっと林さんが管理します。いつか引き継ぐときは → [handover.md](handover.md)）
- このフォルダの `okame/gas/Code.gs`（GASのコード）
- メモ用の紙（「共有トークン」と「初期の暗証番号」を書き写します）

---

## 1. 新しいスプシを作る

1. Chromeで **https://sheets.new** を開く（空のスプシができます）
2. 左上の「無題のスプレッドシート」をクリックし、名前を **お香芽 業務データ** にする
3. メニューの **ファイル → 設定** を開き、「タイムゾーン」を **(GMT+09:00) 東京** にして「設定を保存」

## 2. Apps Script（GAS）を開く

1. スプシのメニューで **拡張機能 → Apps Script** を押す（新しいタブが開きます）
2. 左上の「無題のプロジェクト」をクリックし、名前を **お香芽 業務アプリ** にして「名前を変更」
3. 左の歯車 **プロジェクトの設定** を開き、「タイムゾーン」が **(GMT+09:00) 東京** になっているか確かめる（違ったら直す）
4. 左の **<> エディタ** に戻る

## 3. コードを貼る

1. エディタの中（`function myFunction() { }` と書いてある所）をクリックし、**Ctrl + A** → **Delete** で全部消す
2. エクスプローラーで `okame/gas/Code.gs` を右クリック → **プログラムから開く → メモ帳**
3. メモ帳で **Ctrl + A** → **Ctrl + C**（全部コピー）
4. エディタに戻って **Ctrl + V**（貼り付け）
5. **Ctrl + S**（または上のフロッピーのアイコン）で保存

## 4. 初期設定（setup）を実行する

1. エディタの上にある関数の選び欄（「myFunction」などと出ている所）で **setup** を選ぶ
2. **▷ 実行** を押す
3. 初回だけ「承認が必要です」と出るので、次のように進む
   1. **権限を確認** を押す
   2. 林さんのアカウントを選ぶ
   3. 「このアプリは Google で確認されていません」と出たら、左下の **詳細** → **お香芽 業務アプリ（安全ではないページ）に移動** を押す
      （自分で作ったコードなので心配はいりません。Googleの審査を受けていないという意味です）
   4. **許可**（または「続行」）を押す
4. 下の「実行ログ」に次の2つが出るので、**紙に書き写す**
   - **共有トークン**：英数字の長い文字。タブレットを最初につなぐときに1回だけ入れます
   - **初期の暗証番号**：4桁の数字。店長に伝え、設定画面で好きな番号に変えてもらいます

   > この2つは、チャットやメール、スクショで送らないでください。
   > あとで見たくなったら、スプシのメニュー「お香芽 → 共有トークンを表示」で出せます。暗証番号は表示できません（忘れたら「お香芽 → 暗証番号を作り直す」）。

5. スプシのタブに戻って再読み込み（F5）し、下のタブが次のようにできているか確かめる
   来客／締め／営業日／スタッフ／勤怠／仕入れ／固定費／予定／希望休／操作履歴／設定
   メニューに「**お香芽**」が増えていれば成功です。
   タブ名の横に鍵のマークが付きます。これは「保護」で、林さん以外は直接書き換えられない印です（記録はアプリから直します）。

## 5. Webアプリとしてデプロイする

1. Apps Scriptのタブに戻り、右上の **デプロイ → 新しいデプロイ** を押す
2. 「種類の選択」の歯車を押して **ウェブアプリ** を選ぶ
3. 次のように入れる
   | 項目 | 入れるもの |
   |---|---|
   | 説明 | お香芽 v0.1.0 |
   | 次のユーザーとして実行 | **自分**（林さんのメールアドレス） |
   | アクセスできるユーザー | **全員** |

   > 「全員」にするのは、タブレットをGoogleにログインせずに使うためです。代わりに「共有トークン」がないと何もできないようにしてあります。
4. **デプロイ** を押す（承認を求められたら、4-3と同じように進む）
5. 出てきた **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）を **コピー**

## 6. つながったか確かめる

1. Chromeで新しいタブを開き、コピーしたURLの末尾に **?action=ping** を付けて開く
   例：`https://script.google.com/macros/s/……/exec?action=ping`
2. `{"status":"ok","app":"okame",...}` と出れば成功
   - Googleのログイン画面が出たら、5-3の「アクセスできるユーザー」が「全員」になっていません。「デプロイ → デプロイを管理」で直してください

## 7. URLを渡す

URLをClaudeに渡してください。アプリの設定ファイル（`okame/v2/config.js`）の1か所に入れます。
URLは秘密ではありませんが、**共有トークンは渡さないでください**（タブレットで直接入れます）。

## 8. オーナーと店長に共有する

1. スプシの右上の **共有** を押す
2. オーナーと店長のメールアドレスを入れ、権限を **編集者** にして送信
3. 2人はスプシを開いて記録を見られますが、記録のタブは保護されているので直接は書き換えられません（試しに書こうとすると止められます）。直すのはアプリからです

> 保護は setup を実行するたびにかけ直されます。誰かが保護を外してしまっても、setup をもう一度実行すれば元に戻ります。

## 9. 古いokameのGASを止める

1. 古いokameのスプシを開き、**拡張機能 → Apps Script**
2. **デプロイ → デプロイを管理** → 古いデプロイを選び、**アーカイブ** を押す
3. 古いスプシと管理シートは消さずに残します

---

## あとでGASを直すとき（毎回この流れ）

ClaudeがCode.gsを直したら、次のようにします。**URLは変わりません。**
（`gas/appsscript.json`（許可の設定）が変わったときは、先に [試運転の準備.md](試運転の準備.md) の「許可の設定（appsscript.json）を貼り替える」をします）

1. 手順3と同じように、エディタの中を全部消して、新しいCode.gsを貼って保存
2. 「表を足した」「列を足した」と言われたときは、手順4と同じように **setup** を実行（何度実行しても記録は消えません）
3. 右上の **デプロイ → デプロイを管理** を押す
4. 右上の **鉛筆（編集）** を押す
5. 「バージョン」を **新バージョン** にして、**デプロイ** を押す

> 注意：「新しいデプロイ」を押すとURLが変わり、タブレットがつながらなくなります。直すときは必ず「デプロイを管理 → 鉛筆」です。

## タブレットの準備（アプリをGitHubに上げたあと）

1. タブレットのブラウザ（iPadはSafari、AndroidはChrome）で、Claudeが伝えるアプリのURLを開く
2. ホーム画面に追加する
   - iPad：共有ボタン（□に↑）→ **ホーム画面に追加**
   - Android：右上の︙ → **ホーム画面に追加**（または「アプリをインストール」）
3. ホーム画面のアイコンから開き、**共有トークン** を入れて「つなぐ」
4. 以後は、通信が切れてもホーム画面のアイコンから開けます（入力は端末に保存され、つながったら送られます）

> iPadは、ホーム画面に追加したアイコンから使ってください。Safariのタブで使うと、しばらく開かないうちに端末の保存が消されることがあります。

## 困ったとき

| 起きたこと | すること |
|---|---|
| タブレットで「共有トークンが違います」 | スプシのメニュー「お香芽 → 共有トークンを表示」で確かめて、入れ直す |
| 店長が暗証番号を忘れた | スプシのメニュー「お香芽 → 暗証番号を作り直す」で新しい番号を出し、店長に伝える |
| 暗証番号を5回間違えて入れなくなった | 10分待つ |
| タブレットをなくした・トークンが漏れたかも | Apps Scriptのエディタで関数 **rotateToken** を実行 → 出た新しいトークンを、手元の端末で入れ直す |
| 「タブ『○○』がありません」と出る | スプシのメニュー「お香芽 → 初期設定」を実行 |
| アプリの上に「送れなかった ○件」 | それを押すと中身が出ます。店長モードで「もう一度送る」。直らなければClaudeに見せてください |
