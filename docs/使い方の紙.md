# お香芽アプリ　使い方（A4・1枚）

> 印刷して、タブレットのそばに貼る用です。ボタンの文字は、画面のとおりに書いています。画面の文言を変えたら、ここも直します。
> A4に収めるため、文字は小さめ（10〜11pt）で、2段組にします。

---

## みんな（バイトも店長も）

**入店**　「店内」→ 人数を押す → 種類（飲み放題／単品／イベント）→「入店する」。名前は空でOK。イベントは「1人の単価」（¥3,000／¥4,000／¥5,000 か手打ち）を選ぶ。金額は人数×単価。

**イベントの人数が変わったら**　店内の「イベント」のページで、卓の下の「−」「＋」を押す（1人ずつ。金額もすぐ変わる）。

**追加（おかわりなど）**　卓（カード）をタップ →「+¥500」「+¥800」「+¥1,000」。ほかの金額は、金額を入れて「足す」。間違えたら、その行の「直す」「消す」。

**延長**　卓をタップ →「延長2時間（1人 ¥2,000）」→ 延長する人数を選ぶ →「延長する」。1人でも延長すれば、卓の時間が延びる。人数を間違えたら、その行の「人数を直す」。

**会計**　卓をタップ → 現金／キャッシュレス／ポイントを選ぶ →「○○で受け取る」。金額が空なら、残りの全額。分けて払うときは、金額を入れる。合計に達すると「精算完了・退店しました」。0円の組は「0円で退店する」。

**間違えたとき**
- 入店を間違えた：卓をタップ →「直す」→「入店を削除」→ 理由を選ぶ
- 会計を間違えた：「今日」→「精算済みの組」→「店内に戻す」→ 理由を選ぶ

**レジの出し入れ**（「今日」の画面）
- お金を出す：「レジから出す」→「内訳を入れて出す」→ 出した額を入れる → 内訳を1行ずつ足す（「＋仕入れ」「＋スタッフへの支払い」「＋小口へ」「＋レジに戻す」）→ 合計が合ったら「決定」。お釣りの小銭などは「残り ¥○○ を小口へ」
  - 例：2,000円出した → ＋仕入れ（飲食物・酒屋）1,978円 →「残り ¥22 を小口へ」→「決定」
  - 店長は、あとから「内訳を直す」で直せる
- 小口現金：「今日」の「小口現金」に残高。「小口から払う」「小口からレジに戻す」「入った・出た記録を見る」
- オーナーの補充：「レジに入れる」→ 金額と理由 →「入金を記録」
- オーナーが抜いた分：「レジから出す」→「オーナーが回収」→「回収を記録」（今は店長だけ）

**閉店**　全員を退店させる →「今日」の「閉店・レジ締め」→ レジの現金を数えて入れる →「今日入った人」を選ぶ →「閉店する」。数えた金額が、次の日の開店時の現金になります。

**前の日の閉店を忘れたとき**　次の日の「今日」の画面の上に「10/14：店内に1組残っています／閉店がまだです」と出ます。店長に知らせてください。

**過ぎた日を見る**　「今日」の画面の上の「過ぎた日の締めと会計を見る」で日付を選んで「見る」。その日の締めと会計した組が出ます（見るだけ。直すのは店長）。「今日に戻る」で戻る。

**会計はタブレットだけ**　店長のスマホでは、見るだけ・直すときだけ（2台で同じ卓を同時に触らないため）。

## 店長だけ

- 「分析」「その他（勤怠・仕入れ・固定費・設定）」は、暗証番号を入れて開く。触らずに5分たつか、アプリを閉じると自動でロック。終わったら「店長ロック」。
- 最初の営業日だけ、開店前に「開店時のレジの現金」を入れて「保存」。
- 勤怠・仕入れは、あとからまとめて入れる。
- 月のシフト・店休日・イベントは、「予定」の画面か、スプシの月のタブ（シフトと、団体及びイベント、見込み）から入れられる。
