# 管理シートの取り込み：項目の対応表

林さん向けです。管理シート「シフト及び売上等（管理職員用）」の **9月・10月** を、新しいスプシに取り込むときの対応です（8月は取り込みません）。
金額などの中身はこの文書には書いていません（リポジトリが公開のため）。

## 取り込みのしかた（案）

- 新しいスプシのGASが、**管理シートを直接読みに行く**形にします（スプシのメニュー「お香芽 → 管理シートから取り込む」）
- 取り込み先は2つのタブ
  - **「過去の日別」**：1日1行（日付・シフト・店休日・イベント・各金額）。中身の確認用
  - **「過去の月次」**：月ごとの合計。分析の月次と、スプシの「月次」タブはここから読む
- **何度やり直しても二重になりません**：取り込むたびに、その月（9月・10月）の行をまるごと置き換えます。10月は管理シートに書き足したあと、もう一度取り込めば新しい数字になります
- 列の位置ではなく**見出しの名前**で読みます（9月と10月で列の並びが違うため）

## 新しい設計で別の画面に吸収されるもの

| 管理シート | 新しいアプリ・スプシ |
|---|---|
| 売上（現金・団体・ポイント・キャッシュレス）を手で書く | 来客・会計から自動（支払い方法と種類の2つの軸） |
| 加奈・スタッフの人件費を手で書く | 勤怠から自動（勤務時間×時給＋交通費） |
| 食品支出・その他支出 | 仕入れ（レジからの出金は自動） |
| 家賃・光熱など | 固定費（月1回） |
| シフト・店休日 | 予定（シフトの予定）と閉店（実績）・予定のカレンダー（店休日） |
| 団体及びイベント | 予定（イベント・団体）と、店内の入店（イベント） |
| 合計の行 | 分析の月次・スプシの「月次」タブ |
| 売上目標・イベントの目標 | 設定の「目標」と分析の月次 |
| 希望休のメモ | 予定の「希望休」 |

## 取り込めないもの（管理シートにないもの）

- 来客数・組数：管理シートにないので、9月・10月の月次では空欄（0）になります
- 種類（飲み放題・単品）の内訳：団体売上だけはイベントとして出します

## 質問（推測しないで確かめたいこと）

1. **ラストの担当**：9月・10月にはラストの列がありません。シフトの C 列（1人目）がラストですか？　それとも記録していませんか？
2. **10月の「売上」（J列）**：9月は「現金売上」でしたが、10月は「売上」です。10月の J 列は現金だけですか、それともキャッシュレスなども入った合計ですか？
3. **シフト欄（C列）の黄色の塗り**：9月は水曜（2・9・16・23・30日）、10月は金曜（2・9・16・23・30日）と11日に付いています。何の印ですか？　取り込みに関係しますか？
4. **イベント名（G列）の黄色の塗り**：10月の「1日ママ」（16・17・24日）に付いています。何の印ですか？
5. **10月の「その他支出」（O列）の薄い灰色**：1日おきに付いています。見た目だけ（交互の色）と考えてよいですか？
6. **これから先の日付の金額**：10月の23日・31日の団体売上や、20日以降の加奈さんの金額は、まだ来ていない日の見込みですか？　見込みなら、**今日までの日付だけ取り込む**（それより先は、その日が過ぎてから取り込み直す）でよいですか？
7. **固定費の名前**：9月は「家賃」「ガス電気カラオケ」、10月は「家賃電気」「ガス・カラオケ・Wi-Fi・電話」「保険」と分け方が違います。管理シートの名前のまま取り込みますが、11月からのアプリの固定費の項目（今は 家賃・ガス・電気・カラオケ）を、10月の分け方（家賃電気・ガス・カラオケ・Wi-Fi・電話・保険 など）にそろえますか？
8. **F列の見出し「3 2」**（10月）：4人目のスタッフの欄ですか？
9. **管理シートのURL**：新しいスプシのGASが直接読みに行くので、管理シートのURLを教えてください（林さんのアカウントで開けるものなら、共有の変更はいりません）
