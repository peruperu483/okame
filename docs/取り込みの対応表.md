# 管理シートの取り込み：項目の対応表

林さん向けです。管理シート「シフト及び売上等（管理職員用）」の **9月・10月** を、新しいスプシに取り込むときの対応です（8月は取り込みません）。
金額などの中身はこの文書には書いていません（リポジトリが公開のため）。

## 取り込みのしかた

- スプシのメニュー **「お香芽 → 管理シートから取り込み直す（9月・10月）」**（金額と予定（シフト・イベント）をまとめて取り込む。2026-10-16 に2つのメニューを1つにした）
  - 終わると、月ごとに「金額：○日分・売上の合計」「予定：シフトのある日・店休日・シフトの人数・イベントの件数」と、**10月の売上の合計**が出ます
  - 1回目は管理シートのURLを聞かれるので貼る（2回目からは覚えている。「いいえ」でURLを入れ直せる）
  - 林さんのアカウントで管理シートを開ければ、共有の変更はいりません
- 取り込み先は2つのタブ
  - **「過去の日別」**：1日1行（日付・シフト・店休日・イベント・各金額）。中身の確認用
  - **「過去の月次」**：月ごとの合計。分析の月次と、スプシの「月次」タブはここから読む
- **何度やり直しても二重になりません**：取り込むたびに、その月（9月・10月）の行と列をまるごと置き換えます
- **金額を取り込むのは今日の日付まで**。先の日付の金額は入れません。管理シートに10月の続きを打ったら、もう一度「取り込み直す」を実行してください（直した日の金額も上書きされます）
- 列の位置ではなく**見出しの名前**で読みます（9月と10月で列の並びが違うため）。読めなかった列は、取り込み後のお知らせに出ます
- 確かめたこと（10/15）：9月は、管理シートの「合計」の行と10項目すべて一致。10月は今日までの分の合計が一致

## 月ごとのタブ（9月・10月）

取り込みを実行するたびに、スプシの下のタブを次のように作り直します（何度やっても二重になりません）。

| タブ | 中身 | 見える？ |
|---|---|---|
| **9月・10月** | 管理シートの9月のタブと同じ形・同じ見た目。列は 日／曜日／シフト（列 2〜列 5）／団体及びイベント／加奈／スタッフ／現金売上／団体売上／ポイント売上／食品支出／その他支出／キャッシュレス売上／家賃電気／ガス・カラオケ・Wi-Fi・電話／保険、一番下に合計 | 見える（保護：林以外は直せない） |
| 過去の日別・過去の月次 | アプリの分析が読む取り込みの数字 | 普段は非表示 |
| 月のひな形 | 月のタブの元（管理シートの9月をコピーしたもの） | 非表示 |

- 10月の「売上」の列は現金売上の列に入れる。9月の「家賃」は家賃電気、「ガス電気カラオケ」はガス・カラオケ・Wi-Fi・電話の列に入れる。10月の保険の列は9月の形には元からないので、足した
- 元の9月のタブは A1 が「8月」になっていたので、新しいタブでは「9月」「10月」に直した
- 見た目（緑の見出し・曜日やシフトのチップ・黄色の塗り・¥表示・1行おきの色）は、管理シートの9月のタブをそのままコピーして使う。黄色の塗りは元の位置のまま写す。売上目標などのメモ欄は持ち込まない
- コピーできなかったときは、同じ並び・同じ色で自前で作る（チップは、色付きの塗りで代わりにする）。取り込みが終わったときの表示で分かる
- 今日より先の日は、日付と曜日だけ入る（金額は日が進んでから取り込み直す）
- 見えなくしたタブを見たいときは、スプシの左下の「シート一覧」から表示する

### 11月以降の月のタブ（アプリの記録から）

- **閉店・レジ締めを送るたびに**、その月のタブ（「11月」「12月」…）だけを作り直す。運用開始日より前（試運転）の閉店では作らない。タブは作り直さず、中身だけを書き換える
- スプシのメニュー「お香芽 → 月のタブを作り直す（11月以降）」で、運用開始日以降の月をまとめて作り直せる
- 列は9月・10月と同じ。日ごとの中身は、現金・キャッシュレス・ポイント＝イベント以外の退店した組、団体売上＝イベントの組の合計、人件費＝勤怠（加奈の列とスタッフの列）、食品支出＝仕入れの飲食物、その他支出＝仕入れの飲食物以外、固定費＝月の1日の行
- 固定費は、家賃電気／ガス・カラオケ・Wi-Fi・電話／保険の3つだけが月のタブの列に出る（設定で足した項目は、分析の月次には出るが、月のタブには出ない）
- 試運転の記録は数えない（分析の月次と同じ数え方）

### 月のタブをシフト表として使う（11月以降のタブだけ）

- **来月のタブを先に作る**：メニュー「お香芽 → 来月のタブを作る」。毎月20日の朝9時にも自動で作る（初期設定を実行したあと）
  - 先に入るのは、日付・曜日・店休日の印・シフトの予定（列2〜列5）・団体及びイベントの名前と見込み。金額の列は空
  - 閉店のたびに実績で上書きしていく。シフトは、実績があれば実績、なければ予定
  - 予定のイベントと、実際に入店したイベントの組が同じなら、名前は1つにまとめる
- **列**：日／曜日／シフト（列2〜列5）／団体及びイベント／**見込み**（新しい列）／加奈／スタッフ／現金売上／団体売上／ポイント売上／食品支出／その他支出／キャッシュレス売上／家賃電気／ガス・カラオケ・Wi-Fi・電話／保険（右端）。9月・10月のタブには、見込みの列はありません。「ラスト」の列は、2026-10-16 になくしました（右端の列だったので、ほかの列はずれていません）
- **スプシから打てる列**（林と店長）：シフト（列2〜列5）・団体及びイベント・見込み。ほかの列（金額・合計）は保護のまま
  - シフトはプルダウンで選ぶ。選択肢：列2＝店休日・岡本・加奈、列3＝加奈・優輝、列4＝優輝、列5＝店長・在籍のスタッフ・店休日（列2〜4は設定「shiftColumnChoices」で変えられる）
  - 団体及びイベントは文字で打つ（複数なら「、」で区切る）。見込みは金額
  - 打った内容は、アプリの予定に入る：シフト → 「シフト（予定）」、「店休日」 → その日が店休日、団体及びイベント → 予定（時間・人数は空）、見込み → その日の予定の「売上見込み」（予定が複数ある日は先頭の予定に。予定がない日は「イベント」を足す）
  - アプリの予定を直すと、月のタブにも出る（どちらから直しても同じ内容）
  - 打った名前を消す・変えると、アプリの予定も消える（予定は削除になり、操作履歴に残る）
- **プルダウンの色（チップの色）**：スプシのプルダウンの色は、GASからは付けられません。隠してある **「シフト表のひな形」** に、林さんが手で一度だけ付けます（手順は docs/試運転の準備.md の「シフトのプルダウンの色」）。毎月のタブは、そのひな形をコピーして作るので、同じ色になります
- 9月・10月のタブは、管理シートから取り込んだ表のまま。全部保護で、見込みの列もない
- **タブの名前**：手打ちのタブがある月は「11月（アプリ）」、ない月は「12月」。打つのはアプリのタブ（手打ちのタブで打っても、アプリには入らない）
- **取りこぼしを拾う**：編集のトリガーが動かなかったときも、アプリが予定・営業日を読むとき（1分に1回まで）と、メニュー「スプシで打った予定の取り込みを確かめる」で、打った内容をアプリに入れる

### 9月・10月のシフトとイベントを、アプリの予定に入れる

- メニュー **「お香芽 → 管理シートから取り込み直す（9月・10月）」** で、金額と一緒に入る（何度実行しても二重にならない）
- シフトは **C〜F の4列すべて**（列2〜列5）を入れる。「店休日」の日は、アプリの予定でも店休日
- 団体及びイベントは、名前を「、」で区切って1件ずつ予定にする（種類は「団体」。時間・人数・見込みの金額は空）
- 金額は入れない。9月・10月は運用開始日より前の月なので、売上・月次・カウンターの数字は変わらない（月次は管理シートの数字のまま）
- 先の日（今日より後）の予定も入れる。管理シートで消したイベントは、もう一度実行すると削除になる。アプリで足した人数などは残る
- 取り込んだ営業日の行は、メモに「管理シートの予定から」と入り、「テストの行を消す」で消えない

### 手打ちのタブ（「11月（手打ち）」）

- 試運転のあいだ、店長が管理シートと同じ形で全部手で打つタブ。見た目と列は 9月・10月のタブと同じ（月のひな形のコピー）。日付と曜日だけ入れ、ほかは空。**保護なし**。アプリからは書き込まない
- 一番下（34行目）に「アプリとの差（アプリ − 手打ち）」の行：加奈〜保険の列ごとに、月の合計どうしの差（式。色なし）
- 11月は初期設定で1回だけ作る。12月以降はメニュー「手打ちのタブを作る」で、要る月だけ
- 「突き合わせ」のタブは、2026-10-16 にやめた（色分けの比べ方がわかりにくいため）。初期設定・取り込みで消える

### 現金・キャッシュレス・ポイント・イベントの数え方（月次・月のタブで同じ）

- **現金・キャッシュレス・ポイント**は、イベント以外の組の受け取りです。**イベント（団体）** は、その組の合計を別に数えます（管理シートの「団体売上」と同じ。支払い方法は含めません）。売上＝この4つの合計（ポイントを売上に含めない設定なら、ポイントを引く）
- 分析の月次の「支払い方法」には、イベントの行を別に出します。今日の画面の「支払い方法」と、閉店の「あるはずの現金」は、イベントの受け取りも含めて数えます（レジに入るお金のため）

## 新しい設計で別の画面に吸収されるもの

| 管理シート | 新しいアプリ・スプシ |
|---|---|
| 売上（現金・団体・ポイント・キャッシュレス）を手で書く | 来客・会計から自動（支払い方法と種類の2つの軸） |
| 加奈・スタッフの人件費を手で書く | 勤怠から自動（勤務時間×時給＋交通費） |
| 食品支出・その他支出 | 仕入れ（レジからの出金は自動） |
| 家賃・光熱など | 固定費（月1回） |
| シフト・店休日 | 予定（シフトの予定）と閉店（実績）・予定のカレンダー（店休日） |
| 団体及びイベント | 予定（イベント・団体）と、店内の入店（イベント） |
| 合計の行 | 分析の月次・スプシの「月次」タブ |
| 売上目標・イベントの目標 | 設定の「目標」と分析の月次 |
| 希望休のメモ | 予定の「希望休」 |

## 取り込めないもの（管理シートにないもの）

- 来客数・組数：管理シートにないので、9月・10月の月次では空欄（0）になります
- 種類（飲み放題・単品）の内訳：団体売上だけはイベントとして出します
