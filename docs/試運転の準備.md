# 試運転の準備

林さん向けの手順です。試運転（10月最後の週）の**前日**に、上から順に進めてください。
店長と一緒にやる所には【店長】と書いています。全部で40分ほどです。

用意するもの：パソコン（スプシとApps Scriptを開く）、店のタブレット、テストに使った端末（林さんのスマホなど）、メモ用の紙

---

## 1. GASを最新にする（林・5分）

1. Apps Scriptのエディタで、`okame/gas/Code.gs` の中身に貼り替えて保存
2. 右上の **デプロイ → デプロイを管理 → 鉛筆 → バージョン「新バージョン」 → デプロイ**（URLは変わりません）
3. スプシのタブを開き直す（F5）
4. スプシのメニュー **「お香芽 → 初期設定（タブを作る・直す）」** を1回実行する（何度実行しても壊れません）
   - Googleから「新しい許可」を求められたら、許可してください（スプシの編集と毎月20日の自動の動きのため）
   - 終わりの表示に **「自動の動き（トリガー）を設定しました」** と出れば成功です（出ないときは、もう一度実行）
   - 「締め」のタブに「回収」の列が足されます
5. メニュー「お香芽」に **「テストの行を消す」** と **「共有トークンを作り直す」**、**「突き合わせを作り直す」** があることを確かめる
6. 「お香芽 → 管理シートから取り込む（9月・10月）」を実行し、下のタブに **「9月」「10月」「突き合わせ」** ができることを確かめる（GASの版は 0.10.0）

### シフトのプルダウンの色（林・初めの1回だけ・10分）

月のタブのシフトのプルダウン（チップ）の色は、GASからは付けられないので、隠してあるタブに手で付けます。一度付ければ、毎月のタブが同じ色になります。

1. メニュー「お香芽 → 来月のタブを作る」を実行する（隠しタブ「シフト表のひな形」ができます）
2. スプシの左下の **「シート一覧」（≡）** を開き、**「シフト表のひな形」** を表示する
3. **列 2（C列）の2〜32行目**を選び、メニュー **データ → データの入力規則**（または、セルを右クリック → プルダウン → 編集）を開く
4. 項目（店休日・岡本・加奈）の左にある **色の丸** を押して、色を選ぶ。**店休日は赤。** ほかの人は、赤と見分けやすい色で、**人ごとに決めて、どの列でも同じ色**にする（おすすめ：岡本＝青、加奈＝緑、優輝＝紫）
5. **列 3（D）・列 4（E）・列 5（F）・ラスト（T）** も同じように、同じ人は同じ色にする
6. 「シート一覧」で「シフト表のひな形」を非表示に戻す
7. メニュー **「お香芽 → プルダウンの色を月のタブに反映」** を実行する（今ある11月以降のタブに色が写ります）

> 人が増えたときは、ひな形のプルダウンの項目に足して色を付け、もう一度7をします。ひな形をGASが書き換えることはありません（色が消えないように）。

## 2. 送信待ちを0件にする（林・5分）

テストに使った**すべての端末**でアプリを開き、上の表示を見ます。

- 「送信済み」なら、そのままで大丈夫です
- 「送信待ち ○件」なら、それを押して **「今すぐ送る」**。「送信済み」になるまで待つ

> ここで送っておかないと、次の「テストの行を消す」のあとに、残っていたテストの記録が届いてしまうことがあります。

## 3. テストの行を消す（林・2分）

1. スプシのメニュー **「お香芽 → テストの行を消す」**
2. 消す件数がタブごとに出ます。おおよそ次のとおりならOK（10/15の確認の分）
   | タブ | 件数のめやす |
   |---|---|
   | 来客 | 13行ほど（「テスト」で始まる名前） |
   | 締め | 1行 |
   | レジの出し入れ | 4行 |
   | 営業日 | 1行 |
   | 仕入れ | 2行 |
   | 操作履歴 | 十数行 |
   林さんがスマホで試した分があれば、そのぶん増えます。
3. **「はい」** を押す。終わると「消しました」と件数が出ます

**消えるもの**：名前が「テスト」で始まる来客、試運転の印が付いた行、運用開始日（11/1）より前の日付の行（来客・締め・レジの出し入れ・営業日・仕入れ・操作履歴）
**消えないもの**：スタッフ、予定、希望休、設定、11/1以降の日付の行（先に入れたシフトなど）

> 操作履歴には「テストの行を消す」という行が1つ残ります（何を何行消したかの記録です）。

## 4. 共有トークンを作り直す（林・2分）

1. スプシのメニュー **「お香芽 → 共有トークンを作り直す」** → **「はい」**
2. 新しい共有トークンが出るので、**紙に書き写す**（チャットやメールで送らない）

これで、テストに使った端末は古いトークンのままでは送れなくなります。

## 5. テストに使った端末を片付ける（林・端末ごとに1分）

林さんのスマホなど、テストに使った端末ごとに：

1. アプリを開く。上の表示が **「トークンが違います」** になっています
2. それを押して、いちばん下の **「この端末の記録を消す（テストに使った端末の片付け）」** を開く
3. 「けす」と入れて **「この端末の記録を消す」**
4. 最初の画面に戻ります
   - この先も使う端末なら、新しい共有トークンを入れる
   - もう使わない端末なら、ホーム画面のアイコンを消してよい

> 「トークンが違います」の欄に新しいトークンを入れると、端末に残っていたテストの記録が送られてしまいます。テストに使った端末は、必ず先に「記録を消す」にしてください。

## 6. 店のタブレットに入れる（林・5分）

1. タブレットのブラウザ（iPadはSafari、AndroidはChrome）で https://peruperu483.github.io/okame/v2/ を開く
2. ホーム画面に追加する（iPad：共有ボタン → ホーム画面に追加／Android：︙ → ホーム画面に追加）
3. **ホーム画面のアイコンから**開き、新しい共有トークンを入れて「つなぐ」
4. 「今日」の画面が出ればOK

## 7. 設定を整える【店長】（15分）

タブレットで「その他」→ 暗証番号 → 「設定」。

| 設定 | 入れるもの |
|---|---|
| 暗証番号を変える | **店長が自分で決めた番号**に変える（いちばん最初に） |
| 飲み放題の料金・時間 | 3,000円・120分 |
| ラストオーダーの知らせ | 30分前 |
| 運用開始日 | 2026-11-01（これより前は試運転として集計から外れる） |
| 延長 | 料金と時間が決まっていれば足す（なければ空のまま） |
| ポイントを売上に含める | はい |
| 目標 | 月の売上 1,000,000円・1日の来客数 10人 |
| バイトも、オーナーの回収を入れられる | はい（オーナーがレジから抜いた分を、バイトも入れられる。いいえにすると店長だけ） |
| 店長報酬（月額） | 200,000円（月次の支出に入ります。店長だけが見られます。変えるときはここ） |
| スタッフと時給 | 加奈（2,000円）など。岡本さんは足さない |
| バイトが直せる範囲 | 最初はそのまま（その営業日の記録だけ） |

最後に「変更を保存」を押し、左のメニューの下（縦向きは画面の右上）の **「店長ロック」** を押す。

## 8. 試運転の初日・開店前【店長】（2分）

1. レジの現金を数える
2. 「今日」の画面の「閉店・レジ締め」の欄に出ている **「開店時のレジの現金を入れてください」** に、その金額を入れて保存

これは最初の1回だけです。次の日からは、前の日の閉店で数えた金額を引き継ぎます。

## 9. 試運転のあいだ（毎日）

- 閉店のときに「今日」の画面で **閉店・レジ締め** をする（数えた現金が、次の日の開店時の現金になる）
- レジから買い出しのお金を出したら「レジから出す」、オーナーが補充したら「レジに入れる」
- 気になった所は、画面のスクショとひとことメモを残す
- 上の表示が「送れなかった ○件」「トークンが違います」になったら、林さんに知らせる
- **管理シートにも、これまでどおり入力する**（試運転のあいだは、管理シートとアプリの両方に入れます）
  - 月のタブ（9月・10月）と月次の数字は、完全移行の日までは**管理シートの数字**です。アプリの試運転の記録は、集計に入りません

### 試運転の記録の突き合わせ（林・毎日1分）

1. 営業の翌日の昼に、スプシのメニュー **「お香芽 → 管理シートから取り込む（9月・10月）」** を実行（管理シートの数字が最新になります）
2. 下のタブの **「突き合わせ」** を開く
   - 試運転の日ごとに、アプリの数字と管理シートの数字が並びます（現金・キャッシュレス・ポイント・団体（イベント）・人件費・仕入れ（食品・その他））
   - **「結果」が緑＝一致、赤＝ずれあり**。ずれのある項目は「差」が赤く塗られ、金額が出ます（差＝アプリ − 管理シート）
   - 「管理シートに行なし」＝その日の行を、まだ管理シートに書いていない
3. ずれの原因を店長と確かめる。アプリの直しは店長モードで、管理シートの直しは管理シートで
   - 勤怠・仕入れは、店長があとから入力する決まりです。試運転では入力しないと、その日の人件費・仕入れの差が出ます

> 突き合わせの数字は、運用開始日より前のアプリの記録です。「テストの行を消す」を実行すると、アプリの記録と一緒に突き合わせも空になります。**消す前に**ずれを確かめておいてください。

## 10. 完全移行する（運用開始の日）

- 試運転で問題がなければ、運用開始日から管理シートへの入力をやめます。**初期値は2026-11-01**
- **早めるとき**：店長モードの「その他 → 設定 → 運用開始日（完全移行の日）」を、その日に変える（日付を選んで保存）
  - その日の前日までの数字は管理シート、その日からはアプリの数字になります。月の途中でも合計できます（たとえば10/20からにすると、10月の月次は「10/1〜10/19が管理シート、10/20〜がアプリ」）
  - 完全移行の日が来たら、管理シートへの入力をやめる前に、もう一度「管理シートから取り込む」を実行して、その日の前日までを取り込む
  - 完全移行の日以降のアプリの記録は、試運転の印が付かない（集計に入る）。その前に、下の「試運転の記録をどうするか」を済ませる

### 運用開始（11/1）の前の日：試運転の記録をどうするか

- **残す場合**：何もしなくてよい。試運転の印で集計から外れます。11/1の開店時の現金は、10/31の締めの金額を引き継ぎます
- **消す場合**：3と同じく「お香芽 → テストの行を消す」。運用開始日より前の行がすべて消えます。11/1の開店前に、8と同じように開店時の現金を入れてください

## 困ったとき

| 起きたこと | すること |
|---|---|
| 上の表示が「トークンが違います」 | それを押して、新しい共有トークンを入れる（テストに使った端末なら、先に5の「記録を消す」） |
| 店長が暗証番号を忘れた | スプシのメニュー「お香芽 → 暗証番号を作り直す」で新しい番号を出し、店長に伝える |
| 「テストの行を消す」の件数が多すぎる・少なすぎる | 「いいえ」を押してやめ、Claudeに件数を見せてください |
| 開店時の現金が間違っている | 店長モードで「今日」→「開店時の現金を直す」 |
