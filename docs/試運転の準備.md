### スプシで打った予定の確かめ方（林・3分）

1. メニュー **「お香芽 → スプシで打った予定の取り込みを確かめる」** を実行する
   - 「編集のトリガー：ありませんでした」と出たら、その場で作ります（許可を求められたら許可）。**初期設定を実行していないと、トリガーがありません**
   - 「まだアプリに入っていなかった打ち込み：○行を、いまアプリに入れました」＝前に打って入っていなかった分が、いま入りました
2. **「11月（アプリ）」** のタブのシフトの欄（列2〜列5）に、1つ名前を選ぶ（例：11/3 の列2に「岡本」）
3. もう一度、同じメニューを実行する → **「最後に動いたとき：（時刻） 11月（アプリ） C4 アプリに入れました」** と出れば、トリガーが動いています
4. アプリの「予定」の画面で11月を開き、その日のシフトに出ているか見る（出るまで最大1分。画面を開き直すと読み込みます）
5. 試しに打った名前は、消してください（消すと、アプリの予定からも消えます）

- 打つのは **「11月（アプリ）」** のタブです。**「11月（手打ち）」のタブに打っても、アプリには入りません**
- トリガーが動かなかったときも、アプリが予定や営業日を読むとき（1分に1回まで）に、打った内容を拾ってアプリに入れます

### 許可の設定（appsscript.json）を貼り替える（初めの1回と、このファイルが変わったときだけ）

Apps Script が使う許可（スプシ・メニュー・トリガー・メールアドレス）は `okame/gas/appsscript.json` に書いてあります。ここに書いていない許可は、エディタで実行しても**許可の画面が出ず**、「〜を呼び出す権限がありません」になります。

1. Apps Scriptのエディタの左の **歯車（プロジェクトの設定）** を開き、**「『appsscript.json』マニフェスト ファイルをエディタで表示する」** にチェックを入れる
2. 左の **エディタ（＜＞）** に戻ると、ファイルの一覧に **appsscript.json** が出る。それを開く
3. 中身を全部消して、`okame/gas/appsscript.json` の中身を貼って **保存**（「実行：自分／アクセス：全員」の公開の設定も、このファイルに入っています。今のデプロイと同じ設定です）
4. 関数の選び欄で **setup** を選び、**▷ 実行**。**許可の画面が出る**ので、「権限を確認 → 林さんのアカウント → 詳細 → 移動 → 許可」と進む
   - 許可の一覧には、スプレッドシート・スプシのメニュー・林さんがいないときの実行（トリガー）・メールアドレスに関するものが出ます。全部許可してください
5. 実行ログ（または、スプシから実行したときの表示）に **「自動の動き（トリガー）を設定しました」** と出れば成功
6. **デプロイ → デプロイを管理 → 鉛筆 → 新バージョン → デプロイ**（許可が変わったので、ウェブアプリも新しい版にします。URLは変わりません）

### シフトのプルダウンの色（林・初めの1回だけ・10分）

月のタブのシフトのプルダウン（チップ）の色は、GASからは付けられないので、隠してあるタブに手で付けます。一度付ければ、毎月のタブが同じ色になります。

1. メニュー「お香芽 → 来月のタブを作る」を実行する（隠しタブ「シフト表のひな形」ができます）
2. スプシの左下の **「シート一覧」（≡）** を開き、**「シフト表のひな形」** を表示する
3. **列 2（C列）の2〜32行目**を選び、メニュー **データ → データの入力規則**（または、セルを右クリック → プルダウン → 編集）を開く
4. 項目（店休日・岡本・加奈）の左にある **色の丸** を押して、色を選ぶ。**店休日は赤。** ほかの人は、赤と見分けやすい色で、**人ごとに決めて、どの列でも同じ色**にする（おすすめ：岡本＝青、加奈＝緑、優輝＝紫）
5. **列 3（D）・列 4（E）・列 5（F）** も同じように、同じ人は同じ色にする
6. 「シート一覧」で「シフト表のひな形」を非表示に戻す
7. メニュー **「お香芽 → プルダウンの色を月のタブに反映」** を実行する（今ある11月以降のタブに色が写ります）

> 人が増えたときは、ひな形のプルダウンの項目に足して色を付け、もう一度7をします。ひな形をGASが書き換えることはありません（色が消えないように）。

## 3. テストの行を消す（林・2分）

1. スプシのメニュー **「お香芽 → テストの行を消す」**
2. 消す件数がタブごとに出ます。おおよそ次のとおりならOK（10/15の確認の分）
   | タブ | 件数のめやす |
   |---|---|
   | 来客 | 13行ほど（「テスト」で始まる名前） |
   | 締め | 1行 |
   | レジの出し入れ | 4行 |
   | 営業日 | 1行 |
   | 仕入れ | 2行 |
   | 勤怠・固定費 | 10月に試しに入れた分（11/1より前の日付なので消えます） |
   | スタッフ・予定・希望休 | 名前が「テスト」で始まるものだけ（例：スタッフ「テスト太郎」、予定「テスト会」） |
   | 操作履歴 | 十数行 |
   林さんがスマホで試した分があれば、そのぶん増えます。
3. **「はい」** を押す。終わると「消しました」と件数が出ます

**消えるもの**：名前が「テスト」で始まる来客・勤怠・予定・希望休・スタッフ、試運転の印が付いた行、運用開始日（11/1）より前の日付の行（来客・締め・レジの出し入れ・営業日・仕入れ・操作履歴・勤怠・固定費）
**消えないもの**：名前が「テスト」で始まらないスタッフ・予定・希望休、設定、11/1以降の日付の行（先に入れたシフトなど）

> 操作履歴には「テストの行を消す」という行が1つ残ります（何を何行消したかの記録です）。

## 9. 試運転のあいだ（毎日）

- **会計と入店は、店のタブレットだけで行う**（店長のスマホでは、見るだけ・直すときだけ）。同じ卓を2台で同時に触ったときに入力が消えないように作り直しましたが、本物の2台で確かめるまでは、この決めで進めてください
- 閉店のときに「今日」の画面で **閉店・レジ締め** をする（数えた現金が、次の日の開店時の現金になる）
  - 閉店を忘れたり、店内に組が残ったまま帰ったりした日は、次の日の「今日」の画面の上に **「10/14：店内に1組残っています／閉店がまだです」** と出ます。「その日を開く」から、その日の精算と閉店ができます（バイトは店長に知らせて、店長モードで直します）
- レジから買い出しのお金を出したら「レジから出す → 買い出し」、オーナーが補充したら「レジに入れる」、オーナーがレジから抜いたら「レジから出す → オーナーが回収」（今の設定では、回収は店長だけ）。閉店後・休みの日に入れた分は、店長が日付を選んで入れます（入れた分は、次の日の「今日」の一覧に出て、消せます）
- 試運転のあいだ、今日の画面の **「あと」（月の目標まで）は、10月分は管理シートから取り込んだ数字を使う** ので、アプリで会計しても増えません（11月からアプリの売上で動きます）
- 気になった所は、画面のスクショとひとことメモを残す
- 上の表示が「送れなかった ○件」「トークンが違います」になったら、林さんに知らせる
- **管理シートにも、これまでどおり入力する**（試運転のあいだは、管理シートとアプリの両方に入れます）
  - 月のタブ（9月・10月）と月次の数字は、完全移行の日までは**管理シートの数字**です。アプリの試運転の記録は、集計に入りません

### 月のタブを2つに分ける：「11月（アプリ）」と「11月（手打ち）」（林・見比べるだけ）

「突き合わせ」のタブはやめました。11月は、同じ形のタブを2つ並べ、林さんが目で見比べます。

| タブ | 中身 | 誰が書く | 保護 |
|---|---|---|---|
| **11月（アプリ）** | アプリの記録が自動で入る（今までの「11月」のタブのまま）。シフト・団体及びイベント・見込みは、ここから打つとアプリの予定に入る | アプリ（閉店のたび） | 金額の列と合計は保護 |
| **11月（手打ち）** | **元の管理シートの11月のタブの写し**（シフト・団体及びイベント・金額の列すべて）。見た目と列の並びは管理シートの9月と同じ | **店長は管理シートに打つ**。写すのは「管理シートから取り込み直す」と、毎朝6時ごろの自動の取り込み直し | 打とうとすると注意が出る |

- **店長は、11月以降の売上・支出の数字も、試運転のあいだは元の管理シートに打ちます。** 手打ちのタブには直接打ちません
- 写すたびに、手打ちのタブの日の行をまるごと上書きします（二重になりません）。手打ちのタブに直接打っても、次に写すときに消えます（タブの右上にも書いてあります）
- 毎朝6時ごろに自動で写すので、林さんが押さなくても前日分が入ります。すぐ見たいときは「管理シートから取り込み直す」を押してください
- 毎朝の自動の取り込み直しの結果は、メニュー「スプシで打った予定の取り込みを確かめる」で見られます
- 手打ちのタブの金額は、アプリの売上・月次には入りません。手打ちのタブで打ったシフトや予定も、アプリには入りません
- 手打ちのタブの一番下（34行目）に **「アプリとの差（アプリ − 手打ち）」** の行が1行だけあります。月の合計どうしの差で、加奈〜保険の列ごとに出ます（色は付けません。式なので、どちらを直しても自動で変わります）
  - アプリのタブには「見込み」の列が1つ多いので、列の位置は1つずれていますが、差は同じ項目どうしで出しています
  - 人件費・仕入れ・固定費は、店長がアプリにあとから入れるので、入れるまでは差が出ます
- 2つのタブは隣に並びます（9月・10月・11月（アプリ）・11月（手打ち）・12月…）
- **12月以降**：試運転が終わっていれば、手打ちのタブは要りません。要るときだけ、メニュー **「お香芽 → 手打ちのタブを作る」** で月（例：12月）を入れて作ります。作ると、その月のアプリのタブは「12月（アプリ）」に名前が変わります。管理シートに同じ形の「12月」のタブがあれば、11月と同じように写します
- 手打ちのタブを消しても、初期設定で作り直すことはありません
- 10月の試運転の記録（運用開始日より前のアプリの記録）は、月のタブには出ません。アプリの「今日」の画面（その日を開く）で見て、管理シートと見比べてください

## 10. 完全移行する（運用開始の日）

- 試運転で問題がなければ、運用開始日から管理シートへの入力をやめます。**初期値は2026-11-01**
- **早めるとき**：店長モードの「その他 → 設定 → 運用開始日（完全移行の日）」を、その日に変える（日付を選んで保存）
  - その日の前日までの数字は管理シート、その日からはアプリの数字になります。月の途中でも合計できます（たとえば10/20からにすると、10月の月次は「10/1〜10/19が管理シート、10/20〜がアプリ」）
  - 完全移行の日が来たら、管理シートへの入力をやめる前に、もう一度「管理シートから取り込み直す」を実行して、その日の前日までを取り込む
  - 完全移行の日以降のアプリの記録は、試運転の印が付かない（集計に入る）。その前に、下の「試運転の記録をどうするか」を済ませる

### 運用開始（11/1）の前の日：試運転の記録をどうするか

- **残す場合**：何もしなくてよい。試運転の印で集計から外れます。11/1の開店時の現金は、10/31の締めの金額を引き継ぎます
- **消す場合**：3と同じく「お香芽 → テストの行を消す」。運用開始日より前の行がすべて消えます。11/1の開店前に、8と同じように開店時の現金を入れてください

## 困ったとき

| 起きたこと | すること |
|---|---|
| 上の表示が「トークンが違います」 | それを押して、新しい共有トークンを入れる（テストに使った端末なら、先に5の「記録を消す」） |
| 店長が暗証番号を忘れた | スプシのメニュー「お香芽 → 暗証番号を作り直す」で新しい番号を出し、店長に伝える |
| 「テストの行を消す」の件数が多すぎる・少なすぎる | 「いいえ」を押してやめ、Claudeに件数を見せてください |
| 開店時の現金が間違っている | 店長モードで「今日」→「開店時の現金を直す」 |
